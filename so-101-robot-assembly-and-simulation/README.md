# so-101-robot-assembly-and-simulation

**SO-101 Robot Lab — Exploded View, Build Guide & Playground.**

A guide to the SO-101 robot arm. Explode it into its components, hover a part to learn what it
does (leader arm, motor gearing, servos), then reassemble it and follow the build and set-up
guide to completion.

A playground runs the assembled arm through scenarios so you can see it move before committing
to building one.

## Stack

React 19 · Three.js · TypeScript · Vite

## Run

```bash
npm install
npm run dev
```
