# interactive-storytelling-flipbook-application

**The Sketch Shelf — Six Illustrated Story Sketchbooks.**

A shelf of six hand-illustrated stories. Open one and turn pages like a real flipbook, with a
magnifier you can bring up over any spread to inspect the linework, plus a contents view to
jump between stories.

Every illustration is drawn in code — no image assets ship with the project.

## Stack

React 19 · TypeScript · Vite · CSS

## Run

```bash
npm install
npm run dev
```
