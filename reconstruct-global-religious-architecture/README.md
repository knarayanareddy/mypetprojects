# reconstruct-global-religious-architecture

**Hikari — Seven Sanctuaries, One Night.**

Seven sanctuaries rendered as light. A single continuous journey that begins at sunset and
walks through the dark, each building assembled from its own geometry — the architecture is the
narrative device, not decoration.

Scenes are built from parametric paths in `src/scene/`, with materials and textures generated
at runtime rather than loaded.

## Stack

React 19 · Three.js · TypeScript · Vite

## Run

```bash
npm install
npm run dev
```
