# mypetprojects

A collection of experiments that turned out alright.

Each folder is a self-contained project. Most are visual/interactive explainers built with
React and Three.js; a few are full-stack Next.js apps backed by Postgres.

## The projects

| Project | What it is | Stack |
| --- | --- | --- |
| [AIevolution](AIevolution/) | 60+ years of AI as a painted, code-rendered music video | React, Canvas |
| [P-doom](P-doom/) | A painted music video in nine chapters | React, Canvas |
| [demandradar](demandradar/) | Demand-validation methodology + agent kit (Go / Conditional / Pivot / No-go) | Next.js, Postgres, Python |
| [docatlas](docatlas/) | Distil many documents into one traceable briefing | Next.js, Postgres |
| [expand-tower-dataset-countries](expand-tower-dataset-countries/) | Twenty nations' towers from one shared component vocabulary | React, Three.js |
| [implement-lemo-opuscar-project](implement-lemo-opuscar-project/) | 43 film styles reproduced entirely in code | React, CSS |
| [interactive-camera-anatomy-website](interactive-camera-anatomy-website/) | Four cameras disassembled and rebuilt, then printed | React |
| [interactive-f1-car-simulation](interactive-f1-car-simulation/) | F1 car exploded, rebuilt, and wind-tunnel tested | React, Three.js |
| [interactive-storytelling-flipbook-application](interactive-storytelling-flipbook-application/) | Six illustrated sketchbooks with a magnifier | React |
| [reconstruct-global-religious-architecture](reconstruct-global-religious-architecture/) | Seven sanctuaries rendered as light, one continuous night | React, Three.js |
| [recreate-and-enhance-seijaku](recreate-and-enhance-seijaku/) | A walk through a Kyoto residence, with interactive joinery | React, Three.js |
| [robot-control-interface-development](robot-control-interface-development/) | SO-101 command deck: control, policy server, recordings | Next.js, Three.js, Python |
| [robots-final](robots-final/) | SO-101 control deck + AI model coverage | React, Vite |
| [so-101-robot-assembly-and-simulation](so-101-robot-assembly-and-simulation/) | SO-101 exploded view, build guide, playground | React, Three.js |
| [so-101-robot-development-guide](so-101-robot-development-guide/) | SO-101 lab plus a benchmarked model zoo | React, Three.js |

## Running one

Every project is independent:

```bash
cd <project>
npm install
npm run dev
```
