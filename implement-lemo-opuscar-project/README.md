# implement-lemo-opuscar-project

**OPUSCAR — 43 Film Styles Made Entirely in Code.**

Not an awesome list. Forty-three film looks, each reproduced as pure CSS/SVG rather than
photography — so every style is a live, inspectable, tweakable artifact instead of a static
image. Bilingual UI (English / 中文).

Step through styles with the previous/next controls, or jump by index.

## Stack

React 19 · TypeScript · Vite · CSS

## Run

```bash
npm install
npm run dev
```
