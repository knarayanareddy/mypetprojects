# expand-tower-dataset-countries

**Towers — Twenty Nations, One Construction.** A dataset-driven explorer of how the world's
religious and civic towers are built from the same few parts.

Twenty nations, each tower decomposed into a named component vocabulary — *granite plinth*,
*painted tiers*, *shrine rows*, *kalasha finials* for a Dravidian gopuram; *andesite terraces*,
*stairways*, *bell stupas* for an Indonesian step-mountain stupa; *steel frame*, *curtain wall*,
*setback crown*, *mast & beacon* for a modernist setback tower.

Each nation carries its own material palette and construction logic, so the same component set
renders visibly differently per culture.

## Stack

React 19 · Three.js · TypeScript · Vite

## Run

```bash
npm install
npm run dev
```
