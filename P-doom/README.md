# P-doom

**I'm Upping My P(doom)** — a painted music video, told in nine chapters.

A curtain rises on a researcher, a travelling troupe and a rotating cast of guest monsters.
Chapters advance on a shared timeline, and the whole piece is drawn procedurally — paint and
marker strokes are functions of time, not pre-rendered assets.

## Stack

React 19 · Vite 7 · TypeScript · Canvas 2D

## Run

```bash
npm install
npm run dev
```
