# recreate-and-enhance-seijaku

**Seijaku — A Walk Through a Kyoto Residence.**

A quiet first-person walk through a traditional Kyoto residence. The rooms unfold as you
approach: garden, approach, and the inner rooms beyond.

The centrepiece is the joinery — an interactive exploded view of the timber frame. Hover any
part and it explains what it does; toggle between assembled and exploded, and drag to rotate.
Materials, rooms, gardens and the architectural structure are all inspectable.

Includes a WebGL capability check with a fallback for browsers without it.

## Stack

React 19 · Three.js · TypeScript · Vite

## Run

```bash
npm install
npm run dev
```
