# so-101-robot-development-guide

**SO-101 Lab — Exploded View, Build Guide, Robot Playground & AI Models.**

The fuller SO-101 companion. Exploded view and build guide as before, plus a robot playground
driven by named policies and scenario sets, and a **model zoo** benchmarking which AI models
actually work on this hardware.

Notable detail: ArmnetBench v0.1, a public SO-101 dataset, and coverage of unseen objects on
stage — the cases that separate a demo that works from one that generalises.

## Stack

React 19 · Three.js · TypeScript · Vite

## Run

```bash
npm install
npm run dev
```
