# interactive-camera-anatomy-website

**TEARDOWN — Four cameras, taken apart in front of you.**

An interactive teardown of four classic cameras (instant, kit, mirrorless, and a compact
rangefinder). Each machine is disassembled into its real parts layer by layer, held on the
table as an exploded view, then reassembled.

Ends at the print: upload a photo and it comes out of the virtual printer in the style of the
camera you just rebuilt.

## Stack

React 19 · TypeScript · Vite · CSS

## Run

```bash
npm install
npm run dev
```
